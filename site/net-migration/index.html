Data notes

  • Alaska's migration estimates come from Permanent Fund Dividend applications, an unusually good source that most states lack.
  • The yearly table is the state's official series (vintage 2025); each new vintage can revise earlier years.
  • Migration by age is published as yearly averages over five-year periods, and it counts only people who applied for a dividend, so it runs below the official totals.
